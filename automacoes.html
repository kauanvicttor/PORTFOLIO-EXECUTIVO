Como eu construo

Padrões que se repetem em todos os fluxos

Automação que roda sozinha precisa falhar de forma visível, não repetir o que já fez e respeitar os limites dos sistemas com que conversa. Estes padrões aparecem nos workflows abaixo.

01

Homologação e produção

Webhooks separados para cada ambiente no mesmo desenho, ou versões Homol do workflow, para testar sem tocar no que está em uso.

02

Monitor global de erros

Todo workflow aponta para um fluxo de erro que avisa por e-mail com o nó e a mensagem que falharam.

03

Idempotência

IDs únicos, flags de enviado e checagem de “já processado” em Data Tables evitam mensagem, cadastro ou baixa duplicados.

04

Respeito a limites

Paginação com espera entre chamadas nas APIs e envio de WhatsApp um a um, com intervalo variável, para não ser bloqueado.

05

Portais no próprio n8n

Webhook GET devolve o HTML, POST processa: login, formulários e dashboards sem servidor web à parte.

06

Modular e rastreável

Sub-workflows reutilizáveis por entidade, correlationId de ponta a ponta e logs em CSV enviados diariamente.

Agente de IA

Agente de IA para atendimento no WhatsApp

HG Express · Z-API + Google Gemini · em produção · 56 nós
cliente novo, lead e paciente ativo atendidos com dados reais do sistema
agente-atendimento.workflow10 etapas

Agente que conduz a jornada de quem fala com a empresa pelo WhatsApp: capta dados de quem ainda não é cliente, acompanha leads em negociação e responde pacientes ativos consultando entregas, pagamentos e plano direto no banco.

  • Valida a origem e bloqueia o agente automaticamente quando um atendente humano assume a conversa
  • Texto, áudio transcrito, imagem e documento analisados pelo Gemini e unificados em uma única mensagem
  • Buffer de 15 segundos no Redis junta mensagens enviadas em partes antes de responder
  • Identifica o número na base: cliente novo, lead em tratamento ou paciente convertido
  • Cinco ferramentas SQL para o agente: criar lead, status de entrega, status de pagamento, 2ª via e plano
  • Blindagem médica: a IA nunca orienta sobre medicamentos e aciona um especialista humano
n8n · Z-API · Google Gemini · LangChain Agent · PostgreSQL · Redis
02
Integração B2B

API de integração B2B com a NSTECH

n8n como gateway de API · 13 workflows · 6 endpoints
1 chamada cadastra cliente, filiais, produtos, usuários e quantidades
nstech-api.workflow11 etapas

API REST que recebe da NSTECH os cadastros de clientes e distribui cada item para o produto Active correto (TudoEntregue ou OnSupply), devolvendo o resultado item a item na mesma requisição.

  • 6 endpoints: 4 POST de upsert (clientes, produtos, usuários, quantidades) e 2 GET (contratado × utilizado e log)
  • 6 workflows de API + 7 sub-workflows reutilizáveis por produto e por entidade
  • Ambientes de homologação (mock) e produção no mesmo desenho, com Bearer Token e allowlist de IP
  • Rastreio ponta a ponta por correlationId, com log de entrada, saída e recusa
  • Erro por item sem rejeitar o lote inteiro; liberação automática do cliente no sistema Active
  • Contrato documentado em OpenAPI 3.1, coleção Insomnia e script de testes
n8n · REST · OpenAPI 3.1 · SQL Server · Data Tables · Insomnia
03
Portal

Portal do Cliente “Raio-X”

Portal web servido pelo n8n · dados do Bitrix24 · 72 nós
o cliente acompanha a própria implantação sem depender de e-mail
portal-raio-x.workflow11 etapas

Portal em que o cliente entra com CNPJ e senha e vê, em tempo real, o andamento do projeto de implantação lido direto das tarefas do Bitrix24. O próprio n8n serve o HTML, autentica e responde às ações do cliente.

  • Linha do tempo com 5 etapas (início, planejamento, implantação, go-live e passagem de bastão)
  • Barras de progresso geral e de configurações, árvore de tarefas em 3 níveis
  • Banner de pendências do cliente e calendário de reuniões com link do Teams
  • Cliente registra ciência, aceite e avaliação do treinamento, gravados na tarefa do Bitrix
  • Regras por tags (responsável, ocultar, desativar, pendência do cliente) documentadas em guia para o time
  • Webhook de novos projetos fixa as datas das tarefas automaticamente
n8n · JavaScript · HTML/CSS · Bitrix24 REST · Microsoft Outlook
04
Comunicação

Lembretes de reunião Outlook → WhatsApp

Agendas dos consultores → grupos de WhatsApp dos clientes · 90 nós
cliente avisado antes de cada reunião, sem mensagem duplicada
lembretes-reuniao.workflow11 etapas

A cada 30 minutos o fluxo varre a agenda de cada consultor no Outlook, encontra as reuniões da próxima hora, descobre o grupo de WhatsApp do cliente e envia o lembrete com cadência humana para não ser bloqueado.

  • Loop individual por consultor contorna a limitação de leitura de calendários compartilhados
  • Filtro temporal com padronização de fuso (UTC) e enriquecimento dos dados do evento
  • Busca do grupo em paralelo por domínio e por e-mail do cliente, com descarte de quem não tem grupo
  • Controle de envio por unique_id e limpeza diária do log para não repetir lembretes
  • Disparo de 1 em 1 com templates aleatórios e espera variável, simulando comportamento humano
  • Formulário web com inserção, edição, exclusão e consulta dos vínculos cliente ↔ grupo
n8n · Microsoft Outlook · Data Tables · Google Sheets · API WhatsApp
05
Dados

Pipeline Bitrix24 → Supabase → Grafana

ETL com carga histórica e incremental · 69 nós
11.038 tarefas e 398 projetos na primeira carga, atualizados a cada 20 min
etl-bitrix-supabase.workflow9 etapas

ETL que alimenta um banco PostgreSQL com tarefas, projetos, usuários e horas lançadas no Bitrix24, para que a gestão acompanhe a operação em dashboards no Grafana.

  • Extração de tasks.task.list, sonet_group.get, usuários e task.elapseditem.getlist
  • Paginação por último ID com espera entre chamadas para respeitar o limite da API
  • Modelagem com tabelas bx_* (payload bruto em JSONB + colunas tratadas) e controle de sincronização
  • Carga histórica em lote e incremental a cada 20 min; tags sincronizadas às 2h
  • Conciliação diária marca como excluído o que sumiu do Bitrix, para os painéis filtrarem
n8n · Bitrix24 REST · Supabase / PostgreSQL · Grafana

Provisionamento

Provisionamento automático no Grafana

Self-service via formulário · Grafana HTTP API · 46 nós
de 30+ minutos manuais para cerca de 1 minuto
provisiona-grafana.workflow9 etapas

Um formulário dispara a criação completa do ambiente de dashboards de um novo cliente, sem ninguém clicar no Grafana.

  • Cria organização, usuário, token, pasta e permissões em sequência pela API
  • Cadastra a fonte de dados (SQL Server) do cliente
  • Lista os dashboards modelo, baixa o JSON, adapta por JavaScript e publica por produto
  • Trata usuário já existente vinculando-o à nova organização
  • Envia o link e os dados de acesso por e-mail e devolve o resultado na tela
n8n · Grafana HTTP API · SQL Server · JavaScript · SMTP

Agente de IA no suporte com Bitrix24

GPTMaker + Bitrix24 Open Channels e CRM · 64 nós
primeiro atendimento pelo agente, humano só quando precisa
agente-suporte.workflow9 etapas

Agente que faz o primeiro atendimento nos canais abertos do Bitrix24. O n8n orquestra o que acontece no CRM a cada desfecho da conversa e mantém chat, negócio e chamado ligados.

  • Resolvido: encerra o chat e move o negócio para concluído
  • Não resolvido: transfere para a fila de atendimento humano
  • Grava o ID do chat no negócio para ligar conversa e CRM
  • Roteia chamados internos de produto e N2 mudando a etapa no kanban
  • Ambiente de homologação separado para testar antes de publicar
GPTMaker · n8n · Bitrix24 CRM e Open Channels · webhooks

Treinamento

Plataforma EAD automatizada

Matrícula em massa + páginas de curso geradas com IA · 33 nós
contas, matrículas e acessos sem trabalho manual
ead-matriculas.workflow8 etapas

Portal e API que criam contas, matriculam usuários nos cursos e enviam os acessos. Os usuários podem vir do banco do sistema ou de uma lista manual. Em paralelo, um agente de IA monta as páginas dos cursos a partir do passo a passo e dos vídeos.

  • Resolve a identidade por login ou e-mail antes de criar, evitando conta duplicada
  • Processamento em lote com resultado registrado por usuário
  • Catálogo de cursos consultado na própria API da plataforma
  • Agente de IA gera o HTML de cada curso (CSS inline, módulos em sanfona, vídeos por passo) seguindo diretrizes escritas por mim
n8n · API da plataforma EAD · SQL Server · JavaScript · IA generativa
